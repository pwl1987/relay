# Relay 使用说明(Mac)

1. 打开浏览器,访问 Relay 地址(LAN):`http://10.30.5.80:8787`
2. 输入操作口令登录(口令在 `~/.relay/credentials/web-password`,自行查看,勿外传)
3. 进入工作区后,点「＋ 新建任务」
4. 选择项目(如 LAMICE)
5. 在下方输入框用一句话告诉 Relay 要做什么,点「开始」
6. 之后一直在同一个会话里交流:补充要求、追问、要求返工都可以
7. 看到「⚠ 需要你的决定」时,直接在会话里点「允许 / 批准」或「不允许」即可,Relay 会自动继续
8. 完成后会看到「✓ Relay 已完成本轮工作」结果卡,点「查看修改」看改了什么

右上角「技术详情」平时不用管;需要排查时再展开。

桌面浏览器窗口请不要拉得太窄(窄于手机宽度会变成手机版式)。
