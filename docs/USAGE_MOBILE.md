# Relay 使用说明(手机 VPN)

前提:手机已连上 VPN(Headscale)。

1. 打开浏览器,访问与 Mac 相同的地址:`http://10.30.5.80:8787`
2. 输入操作口令登录(与 Mac 相同)
3. 进入工作区后:点左上角「☰」可切换项目/会话、新建任务、处理待决定
4. 在当前会话直接输入,继续和 Relay 交流(任务运行中也可以补充要求)
5. 看到「⚠ 需要你的决定」时,点「允许 / 批准」即可,会话原地继续
6. 完成后看「✓ 本轮工作完成」结果卡;「查看修改」进简化详情
7. 断网时会提示「连接暂时中断」,不用操作,恢复后自动重连,会话不会丢

可选:在 Safari 里 分享 → 添加到主屏幕,即可像 App 一样全屏使用。
